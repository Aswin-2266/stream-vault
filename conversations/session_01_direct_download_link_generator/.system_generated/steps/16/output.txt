**tdl** (`iyear/tdl`) is a popular, feature-rich Telegram toolkit and downloader written in Go (Golang)[1][2]. It is designed to be fast, lightweight, and capable of handling operations that standard Telegram clients might struggle with[2].

### Key Features
* **High-Speed Downloads:** Utilizes maximum bandwidth[2] and is often faster than official Telegram desktop/mobile clients[1].
* **Protected Content:** Supports downloading files and media from restricted or protected chats where saving/forwarding is normally disabled[1].
* **Resource Efficient:** Low CPU and memory footprint with a single-file startup[2].
* **Advanced Operations:** 
  * Forward messages with automatic fallback and message routing[1].
  * Upload files back to Telegram[1].
  * Export chat histories, members, or subscriber lists to JSON[2].

### Installation Options
You can install `tdl` using various package managers depending on your operating system[3]:

* **Homebrew (macOS / Linux):**
  ```bash
  brew install telegram-downloader
  ```
* **Scoop (Windows):**
  ```bash
  scoop bucket add extras
  scoop install telegram-downloader
  ```
* **Termux (Android):**
  ```bash
  pkg install tdl
  ```
* **Arch Linux (AUR):**
  ```bash
  yay -S tdl
  ```
* **Go Install:**
  ```bash
  go install github.com/iyear/tdl@latest
  ```
